
# Customer Review Sentiment Analysis

## About Project
This project uses Natural Language Processing (NLP)
and Machine Learning to classify customer product
reviews into Positive, Negative, and Neutral sentiments.

## Technologies Used
- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Algorithms
1. Multinomial Naive Bayes
2. Logistic Regression

## Features
- Customer review dataset processing
- Text cleaning and preprocessing
- Lowercase conversion
- Stopword removal
- Lemmatization
- TF-IDF feature extraction
- Sentiment classification
- Model accuracy comparison
- Confusion matrix
- Live sentiment prediction

## Installation

Clone the repository:

git clone https://github.com/YOUR_USERNAME/NLP-Sentiment-Analysis.git

Install dependencies:

pip install -r requirements.txt

Run the project:

python sentiment_analysis.py

## Dataset
The dataset contains customer product reviews
with three sentiment categories:
- Positive
- Negative
- Neutral
